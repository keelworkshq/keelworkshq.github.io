Cloud & DevOps

Cloud infrastructure should not become a full-time problem for your team. Keelworks helps you build, manage and improve AWS, Azure and GCP environments without having to build a large CloudOps team.

What we do

Practical help with your cloud infrastructure

We can help with a specific project, take responsibility for selected parts of your infrastructure or provide ongoing CloudOps support. The scope can grow as your business grows.

  • Cloud infrastructure
    AWS, Azure and GCP environments, accounts, networking, compute, storage and supporting services.
  • Infrastructure as code
    Terraform and automation to make infrastructure easier to manage, reproduce and change safely.
  • CI/CD and deployments
    Build and improve Jenkins, GitHub Actions and other deployment pipelines.
  • Containers and platforms
    Docker, Kubernetes, ECS and other container platforms.
  • Monitoring and reliability
    Monitoring, alerting, observability and operational improvements using tools such as New Relic and Grafana.
  • Cloud cost management
    Identify unnecessary spend, right-size resources and improve how cloud resources are used.
  • Security and patching
    Infrastructure hardening, patch management, access reviews and practical security improvements.
  • Backup and disaster recovery
    Backup checks, recovery planning and improvements to your existing DR approach.
  • Incident support
    Incident response support, with 24x7 on-call available as an add-on.
